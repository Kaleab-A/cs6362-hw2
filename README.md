**Environment for all**

- Google Colab with a GPU (tested on an NVIDIA Tesla T4)
- PyTorch, NumPy and Matplotlib (Colab defaults); `datasets` is installed by the notebook


**How to reproduce each one of the files**

1. Open the notebook in Colab and set Runtime > Change runtime type > GPU.
2. Run all cells and allow Google Drive access when prompted. Results are saved to Drive after every run.
3. If the session disconnects, reconnect and run all cells again. Finished runs are loaded from Drive and skipped.
4. The Figure plots appear at the end of its section, and the Figure 1b and 1c plots at the end of the notebook.
